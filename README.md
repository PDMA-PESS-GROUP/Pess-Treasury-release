# PESS Treasury — Releases

Download the latest version from the **[Releases page](https://github.com/PDMA-PESS-GROUP/Pess-Treasury-release/releases/latest)**.

| System | File |
|---|---|
| Windows (installer, updates itself) | `PESS-Treasury-Setup-<version>.exe` |
| Windows (portable, no updates) | `PESS-Treasury-Portable-<version>.exe` |
| Mac, Apple silicon (M1/M2/M3/M4) | `PESS-Treasury-<version>-arm64.dmg` |
| Mac, Intel | `PESS-Treasury-<version>-x64.dmg` |

Installed copies check for new versions every few hours and update themselves.
Current version: **1.3.0**. This repository only holds release files; the code is private.
